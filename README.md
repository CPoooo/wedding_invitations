# Wedding Invitations

NextJS wedding invitation website (specifically for my Fiance and I)

What dev pays someone else to do their wedding invitation website pshhhhhhhh. We got that on deck over here. 

If you wish to run the repo yourself. You can pull the repo and run (if you need more instructions you probably shouldn't be here XD):   

``` bash
npm run dev
```

Main design is based around these primary functions:
- users can open the invitation (animated + music) 
- scroll the page after opening the invitation, see pretty pictures, videos, etc... (looks like a Pinterest board)
- users can click the rsvp image and then be taken to a form to, well, RSVP

Saved via NEON postgres (easiest postgres db in the world I love you NEON)
